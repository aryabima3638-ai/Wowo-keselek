Tema Hijau Biru untuk Pterodactyl
- Warna utama hijau (emerald), latar gelap kebiruan, scrollbar gradient hijau-biru.
- Install lewat bot: /addtema hijau-biru|Tema Hijau Biru|https://LINK-ZIP|hijau biru,tosca,teal
- Manual: extract ke /var/www/pterodactyl, jalankan bash theme-install.sh, lalu yarn build:production
  dan php artisan view:clear.
- Balikin: cp tailwind.config.js.bak-hijau-biru tailwind.config.js, hapus baris <link ... hijau-biru> di layout, build ulang.
